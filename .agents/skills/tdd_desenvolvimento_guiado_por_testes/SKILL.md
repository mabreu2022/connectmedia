O problema é a dependência entre o código e o teste – você não pode mudar um sem mudar o outro. Nossa meta é sermos capazes de escrever outro teste que “faça sentido” para nós, sem ter que mudar o código (algo que não é possível com a implementação atual). Se você tem detalhes da implementação de SQL de um fornecedor espalhados por todo o código e você decide mudar para outro fornecedor, então descobrirá que seu código é dependente do banco de dados do fornecedor.
