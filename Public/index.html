                                01
                                
Descoberta de Vídeos

                            

                            

                                
A tela de Descoberta exibe todos os vídeos encontrados automaticamente pelo monitor de canais que ainda não foram baixados.

                                
    
                                    
  • ▸ Clique no thumbnail ou no checkbox para selecionar vídeos
    • 
                                    
  • ▸ Use Marcar Todos para selecionar a lista completa visível
    • 
                                    
  • ▸ Escolha o Formato (🎥 MP4 ou 🎵 MP3) antes de "Baixar Marcados"
    • 
                                    
  • ▸ Cada card tem botões individuais MP4 e MP3 para agendar um único vídeo
    • 
                                    
  • ▸ O botão Limpar Tudo remove todos os pendentes sem baixar
    • 
                                

                                

                                    
💡 A lista atualiza automaticamente a cada 15 segundos enquanto a tela está aberta.

                                

                            

                        


                        
                        

                            

                                02
                                
Fila de Downloads

                            

                            

                                
Monitora em tempo real o progresso dos downloads em execução.

                                
    
                                    
  • ▸ A barra de progresso atualiza automaticamente a cada 3 segundos
    • 
                                    
  • ▸ Downloads são processados em sequência pelo worker em segundo plano
    • 
                                    
  • ▸ Após conclusão, o vídeo vai automaticamente para o Acervo
    •

                                03
                                
Canais Monitorados

                            

                            

                                
Gerencie os canais que o sistema monitora automaticamente.

                                
    
                                    
  • ▸ Clique em + Novo Canal e cole a URL do canal do YouTube
    • 
                                    
  • ▸ O monitor roda automaticamente a cada 60 minutos buscando novos vídeos
    • 
                                    
  • ▸ Use Atualizar Agora para forçar uma varredura imediata
    • 
                                    
  • ▸ O botão Excluir remove o canal e todos os seus vídeos da biblioteca
    • 
                                

                            

                        


                        
                        

                            

                                04
                                
Configurações

                            

                            

                                

                                    

                                        
Opções disponíveis

                                        
    
                                            
  • ▸ Pasta de downloads: destino dos arquivos baixados
    • 
                                            
  • ▸ Qtd. de vídeos por canal em cada varredura
    • 
                                            
  • ▸ Tipos de conteúdo: vídeos, shorts e/ou lives
    • 
                                            
  • ▸ Intervalo entre varreduras automáticas (minutos)
    • 
                                        

                                    

                                    

                                        
Arquitetura do sistema

                                        

                                            
● Server.js — API REST :3000

                                            
● popular_e_rodar.js — Monitor

                                            
● worker_download.js — Downloads

                                            
● BIBLIOTECA_YT.FDB — Firebird 5

                                        

                                    

                                

                            

                        


                        
                        

                            

                                05
                                
Gerador de Skills para Antigravity

                            

                            

                                
Extrai conhecimento de vídeos do YouTube e gere arquivos .md prontos para uso como Skills no Antigravity IDE.

                                

                                    
Pipeline de extração inteligente

                                    

                                        YouTube URL(s)
                                        →
                                        oEmbed (Título Auto)
                                        →
                                        yt-dlp / Whisper Local
                                        →
                                        Extração de Comandos & Passo a Passo
                                        →
                                        .agents/skills/
                                    

                                

                                
    
                                    
  • ▸ Auto-Preenchimento de Título: ao colar a URL no modo Vídeo Único, o título é carregado em < 100ms
    • 
                                    
  • ▸ Processamento em Lote: alterne para a aba "Processar em Lote" e cole múltiplos links (um por linha)
    • 
                                    
  • ▸ Whisper AI Local: 100% gratuito e offline para vídeos sem legendas nativas
    • 
                                    
  • ▸ Uso via Terminal: node gerar_skill.js url1 url2 ou node gerar_skill.js --lista links.txt
    • 
                                

                            

                        


                        
                        

                            

                                06
                                
Skills Aprendidas

                            

                            

                                
Consulte todos os conhecimentos já extraídos para o Antigravity IDE.

                                
    
                                    
  • ▸ Diretório Exato no Disco: cada cartão exibe o caminho absoluto do arquivo SKILL.md no computador
    • 
                                    
  • ▸ Botão Copiar Caminho: copia instantaneamente a localização física do arquivo para a área de transferência
    • 
                                    
  • ▸ Link do YouTube: botão direto para assistir ao vídeo original fonte do aprendizado
    • 
                                    
  • ▸ Leitor de Conteúdo: modal interativo para visualizar todo o Markdown estruturado sem abrir o arquivo externamente
    • 
                                

                            

                        


                        
                        

                            

                                07
                                
Central de Logs em Tempo Real ("Big Brother")

                            

                            

                                
Acompanhe todos os eventos do Servidor, Worker e Monitor unificados em um único terminal web sem janelas externas.

                                
    
                                    
  • ▸ Transmissão SSE Ao Vivo: recepção contínua de eventos via Server-Sent Events
    • 
                                    
  • ▸ Filtros Avançados: filtre por fonte (Servidor, Worker, Monitor) ou por nível (Info, Sucesso, Aviso, Erro)
    • 
                                    
  • ▸ Controles Interativos: botões para Pausar/Retomar stream, Limpar console e Copiar logs em 1 clique
    • 
                                    
  • ▸ Auto-scroll: rolagem automática ajustável para acompanhar novas linhas
    • 
                                

                            

                        


                        
                        

                            

                                08
                                
Iniciando o Sistema

                            

                            

                                
O sistema pode ser iniciado de duas formas no Windows:

                                

                                    
# Método Invisível (Sem janelas de terminal):

                                    
iniciar_invisivel.vbs

                                    
# Método Padrão (Com janelas de console):

                                    
iniciar_sistema.bat

                                    
# Ou manualmente em 3 terminais separados:

                                    
node Server.js

                                    
node popular_e_rodar.js

                                    
node worker_download.js

                                

                                
Acesse o sistema em: http://localhost:3000
